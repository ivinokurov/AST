# AST (Adaptive Shadow Transformer) — детекция ограждений и теней

Модель AST предназначена для детекции ограждений и их теней на аэроснимках с учётом положения солнца и типа ограждения.

[Геометрия пары «ограждение–тень»](images/fence_shadow.pdf)

Архитектура основана на Swin Transformer с деформируемым вниманием, раздельными полями смещения для ограждений и теней, а также механизмом перекрёстного внимания с геометрическим приором.

```
data/

├── annotations/     # Аннотации в формате JSON
```

Формат аннотации (JSON):
```json
{
  "gsd": 0.1,
  "sun_azimuth": 2.356,
  "sun_elevation": 0.785,
  "objects": [
    {
      "id": 1,
      "type": "fence",
      "fence_type": 2,
      "bbox": [x, y, w, h, theta],
      "shadow_group_id": null
    }
  ]
}
```

Типы ограждений:
- 0: Деревянный забор
- 1: Металлический забор
- 2: Кирпичный забор
- 3: Живая изгородь

## Обучение

```bash
python train.py \
  --data-root ./data \
  --output-dir ./outputs \
  --epochs 300 \
  --batch-size 8 \
  --lr 2e-4
```

Параметры:
- `--data-root`: Путь к данным
- `--output-dir`: Директория для чекпоинтов и логов
- `--epochs`: Количество эпох обучения
- `--batch-size`: Размер батча
- `--lr`: Начальный learning rate
- `--resume`: Путь к чекпоинту для продолжения обучения

## Инференс

```bash
python inference.py \

  --output-dir ./results \
  --sun-azimuth 2.356 \
  --sun-elevation 0.785 \
  --fence-type 2 \
```

Параметры:
- `--checkpoint`: Путь к чекпоинту модели
- `--image`: Путь к изображению или директории
- `--output-dir`: Директория для результатов
- `--sun-azimuth`: Азимут солнца (радианы)
- `--sun-elevation`: Высота солнца (радианы)
- `--fence-type`: Тип ограждения (0-3)
- `--gsd`: GSD снимка (м/пиксель)
- `--vis-fields`: Визуализировать поля деформации $\Delta_{fence}$ и $\Delta_{shadow}$

## Ключевые компоненты

### Архитектура Backbone
| Этап | Размер выхода | Блоки | Тип внимания | Поле деформации |
|------|---------------|-------|--------------|-----------------|
| 1 | H/4 × W/4 × 64 | 2 | Жёсткое оконное | Нет |
| 2 | H/8 × W/8 × 128 | 2 | Локальное деформируемое | $\Delta_{fence}$ |
| 3 | H/16 × W/16 × 256 | 4 | Полное деформируемое | $\Delta_{fence}$, $\Delta_{shadow}$ |
| 4 | H/32 × W/32 × 512 | 2 | Глобальное деформируемое | $\Delta_{fence}$, $\Delta_{shadow}$ |

### Деформируемое внимание
- Раздельные поля смещения:
  - $s_{fence} = 0.05$ (жёсткие линейные структуры ограждений)
  - $s_{shadow} = 0.35$ (резкие изломы теней на рельефе)
- Билинейная семплировка для субпиксельной точности
- Модуляция по типу ограждения: $\Delta_{shadow}$ корректируется для разных высот и прозрачности

### Перекрёстное внимание
- Связывание ограждений с тенями через геометрический приор
- Кодирование азимута солнца: $PE(\theta_{sun})$
- Учёт глобального контекста освещения сцены

### Функция потерь

$$
L_{total} = L_{det} + 0.1 \cdot L_{def} + 0.5 \cdot L_{cross} + 0.3 \cdot L_{conn}
$$

Компоненты:

- $L_{det}$: Focal Loss + $L_1$ bbox + GIoU (детекция объектов)
- $L_{def}$: Регуляризация градиентов полей смещения (норма Фробениуса)
- $L_{cross}$: Согласованность «ограждение–тень» с проекцией солнца
- $L_{conn}$: Бинарная кросс-энтропия для связности фрагментов теней

### Метрики качества
- mAP@0.5 и mAP@0.5:0.95
- Связность пар «ограждение–тень»
- Доверительные интервалы 95% (bootstrap, 1000 итераций)

## Теоретические свойства

### Приближённая локальная деформационная эквивариантность
Архитектура AST гарантирует, что для любой гладкой деформации $T$:

$$
F(T(I)) \approx T_*(F(I))
$$

с точностью до ошибки интерполяции первого порядка. Это достигается за счёт:
- Преобразования поля смещения как тензора
- Использования деформированных относительных координат в $PE$
- Билинейной семплировки признаков

## Датасеты

Обучение и валидация проводятся на комбинации датасетов:

1. **Fence-Shadow Dataset**: изображения ограждений с тенями
   - Разметка пар «ограждение–тень»
   - Различные типы ограждений и условия освещения

2. **Аэроснимки коттеджных посёлков**: изображения с тенями от ограждений
   - Оценка устойчивости к теневым артефактам
   - Разметка типов ограждений

3. **Лесные и садовые участки**: изображения с живыми изгородями
   - Целевая настройка для пар «ограждение–тень»
   - Разметка теней от растительности
