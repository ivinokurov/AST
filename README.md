# AST (Adaptive Shadow Transformer) — совместная детекция ограждений и их теней на ортофотоснимках малоэтажной застройки

[![Release](https://img.shields.io/badge/release-v1.0.2-blue)](#установка)
[![License](https://img.shields.io/badge/license-Apache--2.0-green)](#лицензия)

Модель AST предназначена для совместной детекции ограждений и их теней на надирных аэрофотоснимках малоэтажной застройки с учётом положения солнца и типа ограждения.

[Геометрия пары «ограждение–тень»](images/fence_shadow.pdf)

Архитектура основана на Swin Transformer с деформируемым вниманием на этапах 2–4, раздельными полями смещения для ограждений и теней, а также механизмом перекрёстного внимания с геометрическим приором по азимуту и высоте солнца.

## Подготовка данных

Ожидаемая структура датасета:
```
data/
├── fsad/                # Fence & Shadow Aerial Dataset
│   ├── images/          # Ортофотоснимки (.png, .jpg)
│   ├── annotations/     # Аннотации в формате JSON
│   └── splits/          # Списки файлов для train/val/test (80/10/10)
├── synthetic/           # 2000 синтетических сцен (Unreal Engine 5 + Colosseum)
│   ├── images/
│   ├── annotations/
│   └── heightmaps/      # Карты высот для $\omega_{\text{relief}}$
└── ciyutuo/             # Ciyutuo Village Dataset (65 изображений, кросс-валидация)
    ├── images/
    └── annotations/
```

Формат аннотации (JSON):
```json
{
  "gsd": 0.021,
  "sun_azimuth": 2.356,
  "sun_elevation": 0.785,
  "yaw": 0.0,
  "objects": [
    {
      "id": 1,
      "type": "fence",
      "fence_type": 2,
      "bbox": [x, y, w, h, theta],
      "height": 1.8,
      "shadow_group_id": null
    },
    {
      "id": 2,
      "type": "shadow",
      "bbox": [x, y, w, h, theta],
      "shadow_group_id": 5
    }
  ]
}
```

Типы ограждений ($\tau$):
- 0: Сплошное ($h \approx 1{,}8$ м)
- 1: Решётчатое ($h \approx 1{,}5$ м)
- 2: Штакетное ($h \approx 1{,}2$ м)
- 3: Комбинированное ($h \approx 1{,}6$ м)

## Обучение

Двухстадийное обучение:

**Стадия 1: Предобучение на синтетических данных (30 эпох)**
```bash
python train.py \
  --data-root ./data/synthetic \
  --output-dir ./outputs/stage1 \
  --epochs 30 \
  --batch-size 8 \
  --lr 1e-4 \
  --stage pretrain
```

**Стадия 2: Донастройка на реальных данных FSAD (90 эпох)**
```bash
python train.py \
  --data-root ./data/fsad \
  --output-dir ./outputs/stage2 \
  --epochs 90 \
  --batch-size 8 \
  --lr 1e-4 \
  --stage finetune \
  --resume ./outputs/stage1/best_model.pth
```

Параметры:
- `--data-root`: Путь к данным
- `--output-dir`: Директория для чекпоинтов и логов
- `--epochs`: Количество эпох обучения
- `--batch-size`: Размер батча
- `--lr`: Начальный learning rate (AdamW, косинусное затухание, warmup 500 итераций)
- `--stage`: Этап обучения (`pretrain` или `finetune`)
- `--resume`: Путь к чекпоинту для продолжения обучения

## Инференс

```bash
python inference.py \
  --checkpoint ./outputs/stage2/best_model.pth \
  --image ./test_image.png \
  --output-dir ./results \
  --sun-azimuth 2.356 \
  --sun-elevation 0.785 \
  --fence-type 2 \
  --gsd 0.021 \
  --vis-fields
```

Параметры:
- `--checkpoint`: Путь к чекпоинту модели
- `--image`: Путь к изображению или директории
- `--output-dir`: Директория для результатов
- `--sun-azimuth`: Азимут солнца (радианы)
- `--sun-elevation`: Высота солнца (радианы)
- `--fence-type`: Тип ограждения $\tau \in \{0,1,2,3\}$
- `--gsd`: GSD снимка (м/пиксель)
- `--vis-fields`: Визуализировать поля деформации $\Delta_{\text{fence}}$ и $\Delta_{\text{shadow}}$

## Ключевые компоненты

### Архитектура Backbone
| Этап | Размер выхода | Блоков | Внимание | Поле деформации |
|------|---------------|--------|----------|-----------------|
| 1 | $H/4 \times W/4 \times 96$ | 2 | Оконное ($7\times7$) | Нет |
| 2 | $H/8 \times W/8 \times 192$ | 2 | Деформируемое | $\Delta_{\text{fence}}$ |
| 3 | $H/16 \times W/16 \times 384$ | 6 | Деформируемое | $\Delta_{\text{fence}}, \Delta_{\text{shadow}}$ |
| 4 | $H/32 \times W/32 \times 768$ | 2 | Деформируемое | $\Delta_{\text{fence}}, \Delta_{\text{shadow}}$ |

Деформируемое внимание: $K = 4$ позиции семплирования на $L = 4$ масштабах пирамиды, 8 голов по 32 измерения. Декодер: 6 слоёв, $N = 300$ объектных запросов. Шейка: выравнивание до $C = 256$ свёртками $1\times1$ + GroupNorm.

### Деформируемое внимание
- Раздельные поля смещения:
  - $s_{\text{fence}} = 0{,}05$ (плавные деформации ограждений)
  - $s_{\text{shadow}} = 0{,}35$ (резкие изломы теней на рельефе)
- Билинейная семплировка для субпиксельной точности
- Смещения инициализируются вблизи нуля (в начале обучения — локальное окрестностное внимание)

### Головки предсказания

- **Классификация** — фокальная потеря, смещение инициализируется $-\ln((1-\pi)/\pi)$ при $\pi = 0{,}01$
- **Регрессия OBB** — центр $(x, y)$, размеры $(w, h)$, угол через $(\sin\theta, \cos\theta)$
- **Типология** — линейный слой на 4 класса, кросс-энтропия
- **Положение солнца** (вспомогательная) — азимут через синус-косинусную пару, высота через $\sigma(\cdot) \cdot \pi/2$

### Метрики качества

- mAP@0.5 на основе Rotated IoU
- FNR (False Negative Rate) $\downarrow$
- FPR (False Positive Rate) $\downarrow$
- Доля разорванных теней $\downarrow$
- Доверительные интервалы 95% (bootstrap, 1000 итераций)

## Датасеты

Обучение и валидация проводятся на комбинации трёх наборов данных:

1. **FSAD (Fence & Shadow Aerial Dataset)** — 650 ортофотоснимков коттеджной застройки с ручной разметкой
   - БПЛА, разрешение $5280\times3956$, высота полёта 80–120 м, камера строго в надир
   - 2023–2025 гг., четыре региона России (Московская, Калужская, Тульская, Тверская области)
   - Ортотрансформированы в Agisoft Metashape, GSD 2,1–2,8 см/пикс
   - Разметка: OBB, класс (fence/shadow), тип ограждения, `shadow_group_id`
   - Состав: 1240 объектов, 1060 пар; разбиение 80/10/10 стратифицированно

   | Тип ограждения | Изображений | Объектов | Пар |
   |---|---|---|---|
   | Сплошное | 220 | 440 | 380 |
   | Решётчатое | 180 | 320 | 280 |
   | Штакетное | 150 | 300 | 250 |
   | Комбинированное | 100 | 180 | 150 |
   | **Всего** | **650** | **1240** | **1060** |

2. **Синтетические данные** — 2000 изображений, сгенерированных в Unreal Engine 5 с плагином Colosseum
   - Четыре типа ограждений, рельеф с углами $0\text{–}30^\circ$, азимут $30\text{–}150^\circ$, высота солнца $20\text{–}60^\circ$
   - Виртуальная камера строго в надир, GSD 2,1–2,8 см/пикс
   - Минимизация domain gap: гистограммная эквализация, color jittering, симуляция атмосферной дымки

3. **Ciyutuo Village Dataset** — 65 изображений для кросс-валидации (Китай)
   - [Ссылка на датасет](https://www.geodoi.ac.cn/WebEn/doi.aspx?Id=3607)
   - Ни одно изображение не использовалось при обучении и валидации

## Требования к оборудованию

- GPU: 2× NVIDIA A100 (80 ГБ) или аналог
- Время обучения: ~8 часов (30 эпох синтетика + 90 эпох реальные данные)
- Размер входа: $1024 \times 1024$ пикселей
- Оптимизатор: AdamW, начальный lr $10^{-4}$, weight decay 0,01
- Фреймворк: PyTorch 2.0+
